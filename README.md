# MsoftAI

Browser-based manifold block design by [MindYards](https://mindyards.in). No CAD package required.

MsoftAI lets a designer size a manifold block, place standard cavities, ports and valve footprints on its six faces from a library, and lay out the internal passages, entirely in the browser.

## Status

Phase 1, block design, in progress. See the project plan in the issues.

## Develop

```
npm install
npm run dev
```

`npm test` runs the geometry model tests. `npm run build` type-checks and produces `dist/`.

## Deploy

Every push to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
The site is served at https://msoftai.mindyards.in (CNAME in `public/`).

## Library

`public/library/cavities.json` and `footprints.json` are generated by `tools/convert-library.mjs`
from the legacy data file. The library will be rebuilt from manufacturer catalogues and standards.
